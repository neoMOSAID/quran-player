NAME
    quran-daemon - Quran Player Daemon

SYNOPSIS
    quran-daemon [COMMAND] [ARGUMENTS]...

DESCRIPTION
    The Quran Player Daemon is a Linux-native background service that provides
    Quranic verse audio playback with synchronized desktop verse display via
    Conky. It supports verse-by-verse playback with auto-advance, persistent
    playback state across sessions, repeat ranges, an optional Conky desktop
    overlay, and a PyQt5 tray GUI controller.

    The daemon communicates with clients over a UNIX domain socket and is
    configured via an INI-style configuration file.

COMMANDS
    start
        Start the daemon. Initializes the audio subsystem, launches Conky
        (if enabled), binds the control socket, and begins listening.

    stop
        Stop the daemon gracefully. Releases the audio device, terminates
        Conky, and removes socket and PID files.

    play
        Resume audio playback from the last saved verse.

    pause
        Pause the current playback, keeping the position.

    toggle
        Toggle between play and pause.

    next / prev
        Advance to / return to the next / previous verse. Wraps across
        surah boundaries.

    goto <ayah>
        Jump to a specific ayah within the current surah. Honours any active
        repeat range.

    load <surah>[:ayah]
        Load a surah (from its beginning) or a specific verse. Loading a
        verse clears any active repeat range.

    repeat <form>
        Set a repeat range. Forms:
          <surah>               Repeat an entire surah
          <start>:<end>         Repeat a range within the current surah
          <surah>:<start>:<end> Repeat a range in the named surah
          off                   Turn repeat mode off

    repeat_off
        Same as 'repeat off'.

    ns / ps
        Load the next / previous surah from its beginning. Clears any active
        repeat range.

    dir <path>
        Change the audio directory and reload the current verse.

    conky_on / conky_off / conky_toggle
        Start / stop / toggle the Conky desktop verse display without
        stopping playback.

    conky_config / conky_config_defaults / conky_config_reset / conky_config_set
        Inspect / show defaults / reset / validate-and-save the Conky display
        config (JSON).

    config_get / config_defaults / config_set
        Inspect / reset / validate-and-save config.ini.

    reload_config
        Re-read config.ini from disk and refresh daemon state.

    status
        Print a JSON snapshot of the daemon state.

    info
        Print a detailed diagnostic report.

    cleanup
        Remove stale runtime files (PID, socket) when no daemon is running.

    config
        Regenerate config.ini to defaults.

    about / help
        Show project info and the full command reference.

CONFIGURATION
    The daemon uses an INI-style configuration file at:

        ~/.config/quran-player/config.ini

    The configuration file has two sections: [daemon] and [conky].

    -----------------------------------------------------------------
    [daemon] Section
    -----------------------------------------------------------------
    max_log_size
        Maximum size (in bytes) of the log file before rotation.
        Default: 1000000.

    log_level
        Log verbosity level. Possible values:
        CRITICAL, ERROR, WARNING, INFO, DEBUG, or DISABLED.
        Default: INFO.

    files_directory
        Directory containing audio files (SSSAAA.mp3). Empty means
        use the bundled sample directory:
        ~/.config/quran-player/sample/

    -----------------------------------------------------------------
    [conky] Section
    -----------------------------------------------------------------
    enable
        Show the current verse on the desktop via Conky. yes/no.
        Default: yes.

    executable
        Path to the conky executable. Empty means auto-detect from PATH.

    -----------------------------------------------------------------
    Conky Display Config (JSON)
    -----------------------------------------------------------------
    The fine-grained Conky display config lives at:

        ~/.config/quran-player/conky_config.json

    Edit it via 'conky_config_get' / 'conky_config_set', or through the
    GUI's "Conky Config" dialog. Invalid JSON or schema violations are
    rejected before anything is written.

FILES
    daemon.py
        The main daemon entry point.

    quran_gui.py
        PyQt5 tray controller.

    quran_search.py
        Search tool (CLI and interactive RTL dialog).

    install.py
        Linux-native installer. No root required.

    default_config.ini
        Default configuration template.

    config.ini
        User configuration file (~/.config/quran-player/config.ini).

    conky_config.json
        User-editable Conky display config.

    quran-daemon (installed)
        CLI wrapper, typically at ~/.local/bin/quran-daemon.

    daemon.sock
        Control socket used for inter-process communication.

    daemon.pid
        File storing the daemon's process ID.

    daemon.log
        Log file for daemon events.

USAGE EXAMPLES
    Install:
        python install.py

    Start the daemon:
        quran-daemon start

    Stop the daemon:
        quran-daemon stop

    Toggle playback:
        quran-daemon toggle

    Load a specific verse:
        quran-daemon load 2:255

    Repeat a range of verses:
        quran-daemon repeat 10:15

    Display status:
        quran-daemon status

    Generate a new configuration file:
        quran-daemon config

    Display help:
        quran-daemon help
